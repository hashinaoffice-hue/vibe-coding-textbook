바이브 코딩 백과사전의 용어 · 챕터 · 해결법을 찾는 플로팅 검색 창이에요. 어느 앱을 쓰다가도 `\` 키(한국어 키보드는 `₩`)를 빠르게 세 번 누르면 떠요.

## 내려받기

| 컴퓨터 | 파일 |
|---|---|
| Windows | `VibeCodingDictionary-Setup-…-x64.exe` |
| Mac (M1 · M2 · M3 · M4) | `VibeCodingDictionary-…-mac-arm64.dmg` |
| Mac (인텔) | `VibeCodingDictionary-…-mac-x64.dmg` |

## 처음 열 때

서명하지 않은 개인용 앱이라 처음 한 번 경고가 떠요.

- **Windows**: "Windows의 PC 보호" 창에서 **추가 정보 → 실행**
- **Mac**: dmg를 열어 앱을 응용 프로그램 폴더로 옮긴 뒤 실행해요. 막히면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **그래도 열기**를 눌러요. 이어서 `\` 세 번 단축키를 쓰려면 같은 화면의 **손쉬운 사용**(필요하면 **입력 모니터링**)에서 앱을 켜고 다시 실행해요.

## 쓰는 법

- 컴퓨터를 켜면 자동으로 켜져서 뒤에서 기다려요(창은 안 떠요). 끄려면 트레이 메뉴의 **컴퓨터를 켤 때 자동 실행**을 꺼요

- `\` 세 번: 열기, 떠 있을 때 `\` 두 번: 닫기 (누른 `\`는 쓰던 앱에도 입력돼요)
- `↑` `↓` 고르기, `Esc` 지우기 · 숨기기
- 뜻풀이 속 점선 밑줄 낱말을 누르면 그 용어의 뜻이 말풍선으로 떠요
- '해결법' 탭: 실습에서 막혔을 때의 증상과 해결법을 낱말로 찾아요(예: 로그인, 배포)
- 작업 표시줄 · 메뉴 막대의 돋보기 아이콘: 컴퓨터를 켤 때 자동 실행, 교과서 열기, 종료
