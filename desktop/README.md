# 바이브 코딩 사전 (데스크톱 위젯)

바이브 코딩 백과사전 네 권의 **용어 · 챕터를 찾는 작은 플로팅 검색 창**이에요. 어느 앱을 쓰다가도 `\` 키를 빠르게 **세 번** 누르면 화면 위에 떠요. 글자를 입력하면 바로 아래에 단어 사전처럼 결과가 나와요.

- 용어: 낱말 · 원어 · 읽는 법 · 뜻 · 어느 권 몇 챕터에 나오는지
- 챕터: 제목 · 한 줄 설명 · 권 · Part
- 위쪽 탭으로 `모두 · 용어 · 챕터`를 나눠 볼 수 있어요
- `↑` `↓`로 고르고, `Esc`는 입력을 지우고 한 번 더 누르면 창을 숨겨요
- 창은 다른 앱 위에 떠 있고, 위쪽 막대를 끌어 옮길 수 있어요
- 위쪽 오른쪽 버튼으로 화면 모드를 `시스템 → 라이트 → 다크` 순서로 바꿔요. 고른 모드는 다음에 켤 때도 그대로예요
- 작업 표시줄(Windows) · 메뉴 막대(Mac)의 돋보기 아이콘: 사전 열기, 교과서 열기, 컴퓨터를 켤 때 자동 실행, 종료

브라우저에서도 같은 화면을 쓸 수 있어요: https://vibe-coding-textbook-theta.vercel.app/widget.html (단축키 없이)

## 내려받아 설치하기

**https://github.com/hashinaoffice-hue/vibe-coding-textbook/releases/latest** 에서 내 컴퓨터에 맞는 파일을 받아요.

| 컴퓨터 | 파일 |
|---|---|
| Windows | `VibeCodingDictionary-Setup-…-x64.exe` |
| Mac (M1 · M2 · M3 · M4) | `VibeCodingDictionary-…-mac-arm64.dmg` |
| Mac (인텔) | `VibeCodingDictionary-…-mac-x64.dmg` |

설치 파일은 GitHub Actions(`.github/workflows/desktop-release.yml`)가 만들어 올려요. `desktop/`이 바뀌어 올라오면 자동으로 다시 만들고, 새 버전으로 내려면 `package.json`의 `version`을 올려요.

## 개발용으로 실행하기

[Node.js](https://nodejs.org) LTS가 필요해요. 이 `desktop` 폴더에서 Claude Code에게 이렇게 맡기면 돼요.

```
desktop 폴더에서 npm install 하고 npm start로 실행해줘
```

직접 할 때는 터미널에서:

```
cd desktop
npm install
npm start
```

## 내 컴퓨터에서 설치 파일 만들기

보통은 위의 Releases에서 받으면 돼요. 직접 만들 때는 **쓰는 운영체제에서** 만들어야 해요(Windows용은 Windows에서, Mac용은 Mac에서).

```
npm run dist
```

`release` 폴더에 Windows는 `.exe` 설치 파일, Mac은 `.dmg`가 생겨요.

## 켜지는 방식

- **컴퓨터를 켜면 자동으로 켜져요.** 창은 띄우지 않고 뒤에서 기다리다가 `\` 세 번에 떠요. 설치하고 처음 켤 때 자동 실행이 켜지고, 끄고 싶으면 트레이 메뉴에서 **컴퓨터를 켤 때 자동 실행**을 꺼요
- 설치하고 **처음 켤 때만** 안내로 창이 한 번 떠요
- Windows에서 시작 메뉴로 직접 켜면 창이 바로 떠요(자동 실행 때는 안 떠요). 이미 켜져 있을 때 다시 실행해도 창이 떠요
- Mac은 처음 자동 실행을 켤 때 "로그인 항목에 추가됨" 알림이 뜰 수 있어요. **시스템 설정 → 일반 → 로그인 항목**에서 확인 · 끄기를 할 수 있어요

## 알아 둘 것

- **`\` 세 번은 지금 쓰던 앱에도 그대로 입력돼요.** 글을 쓰던 칸이었다면 `\\\`를 지워 주세요. 단축키는 `\` 키만 세고, 키 입력을 가로채지 않아요.
- **한국어 키보드**에서는 `\` 키가 `₩`로 표시돼 있을 수 있어요. 같은 키라서 그대로 쓰면 돼요.
- **0.7초 안에** 세 번 눌러야 해요. 천천히 누르면 반응하지 않아요.
- **Mac**은 다른 앱에서 누른 키를 알려면 권한이 필요해요. 처음 실행할 때 안내가 뜨면 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**(필요하면 **입력 모니터링**도)에서 이 앱을 켜고 다시 실행해요. `npm start`로 실행할 때는 목록에 `Electron`이나 터미널 앱으로 보일 수 있어요. 권한이 없어도 메뉴 막대 아이콘으로는 열 수 있어요.
- **처음 여는 설치 파일 경고**: 서명하지 않은 개인용 앱이라 Windows는 "PC 보호" 창에서 **추가 정보 → 실행**, Mac은 Finder에서 **오른쪽 클릭 → 열기**로 한 번 허락해요.
- **내용 업데이트**: 앱이 켜질 때 공개 사이트의 `search.json`을 받아 와요. 교과서가 바뀌면 다음에 켤 때 반영되고, 바로 받고 싶으면 트레이 메뉴의 **교과서 내용 새로 받기**를 눌러요. 인터넷이 없으면 마지막으로 받아 둔 내용을 써요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `main.js` | 창 · 트레이 아이콘 · `\` 세 번 감지 · 검색 자료 받기 |
| `preload.js` | 화면에 꼭 필요한 기능(자료 받기 · 숨기기)만 열어 줘요 |
| `widget.html` | 검색 화면. 사이트 배포 때 `dist/widget.html`로도 복사돼요 |
| `assets/` · `build/` | 트레이 아이콘 · 앱 아이콘 |

검색 자료(`search.json`)는 저장소 루트의 `scripts/build.mjs`가 `index.html`에서 뽑아 사이트와 함께 배포해요.
