# 바이브 코딩 백과사전

바이브 코딩을 수준별로 배우는 교과서 모음입니다. 첫 화면에서 교과서를 고르고, 1920×1080 슬라이드로 넘겨 봅니다.

- 첫 화면: 원자 도트 인터랙션, 챕터·용어 검색 (`/` 키), 수준별 교과서 회전
- 슬라이드 교과서 (← → 키), Part마다 움직이는 4:3 그림, 학습 목표, 챕터 체크리스트, AI 요청 예시
- 챕터를 누르면 개념 · 핵심 포인트 · 예시 · 용어 읽는 법 팝업
- 블랙 + 에메랄드 다크 모드 / 라이트 모드

## 보기

`index.html`을 브라우저로 열면 됩니다. 외부에서 불러오는 것은 Google Fonts뿐입니다. 주소 끝에 `#book`을 붙이면 입문용, `#novice`를 붙이면 초보자용이 바로 열립니다.

## 입문용 · 바이브 코딩 교과서

컴퓨터 용어부터 AI와 함께 앱을 만들어 배포하기까지. 12 Parts · 68 챕터 · 약 35시간 + 졸업 프로젝트 1–2주.

| 단계 | Part |
|---|---|
| 1단계 기초 체력 | 00 오리엔테이션 · 01 컴퓨터 기초 · 02 터미널과 환경 · 03 웹의 동작 |
| 2단계 코드 읽기 | 04 프로그래밍 기본 · 05 프론트엔드 · 06 백엔드와 데이터 |
| 3단계 AI와 만들기 | 07 Git 버전 관리 · 08 AI 협업법 · 09 디버깅과 품질 |
| 4단계 내보내기 | 10 배포와 운영 · 11 졸업 프로젝트 |

## 초보자용 · 바이브 코딩 실습서

AI 요약 메모장 하나를 v1 → v4로 키우며 기획부터 배포까지 직접 해 봅니다. 9 Parts · 39 챕터 · 약 20시간 + 졸업 프로젝트 1–2주. 챕터마다 '깊게'(나중에 고치기 어려운 것) 또는 '가볍게'(AI에게 맡길 것) 표시가 있고, Part마다 따라 하기 · 막혔을 때 실습 슬라이드가 붙습니다.

| 단계 | Part |
|---|---|
| 1단계 준비 | 00 시작하기 · 01 AI에게 작업대 맡기기 · 02 안전망: Git |
| 2단계 만들고 저장하기 | 03 v1 첫 화면과 첫 배포 · 04 v2 데이터 저장 |
| 3단계 지키고 똑똑하게 | 05 v3 로그인과 내 데이터 · 06 v4 AI 요약 기능 |
| 4단계 혼자 서기 | 07 막혔을 때 · 08 졸업 프로젝트 |
