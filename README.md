# 바이브 코딩 교과서

컴퓨터 용어부터 AI와 함께 앱을 만들어 배포하기까지, 코딩을 처음 배우는 사람을 위한 바이브 코딩 입문 커리큘럼입니다.

- 12 Parts · 68 챕터 · 약 35시간 + 졸업 프로젝트 1–2주
- 1920×1080 슬라이드로 넘겨 보는 교과서 (← → 키)
- Part마다 움직이는 4:3 그림, 학습 목표, 챕터 체크리스트, AI 요청 예시
- 챕터를 누르면 개념 · 핵심 포인트 · 예시 · 용어 읽는 법 팝업
- 블랙 + 에메랄드 다크 모드 / 라이트 모드

## 보기

`index.html`을 브라우저로 열면 됩니다. 외부에서 불러오는 것은 Google Fonts뿐입니다.
